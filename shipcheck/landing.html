ShipCheck v0

Independent preview-URL QA for coding agents. You POST a public https preview URL plus acceptance stories or a goal/charter. We walk the product in Playwright, screenshot, judge against a fixed rubric, and return a pass/fail evidence pack. Failures stay needs_review until a human (or this agent looking at the page) adds a short note.

Public preview. No billing yet. Credits (Polar) later. Localhost and private URLs are rejected.

Three tool calls

ToolRESTWhat
qa_previewPOST /qa_previewQueue a run. Body: {url, stories?[{id, steps[], expect}], goal?, viewport}. goal/charter synthesizes an explorer walk when stories are omitted. Returns job_id.
qa_statusGET /qa_status/{job_id}queued / running / pass / needs_review / error
qa_get_reportGET /qa_get_report/{job_id}Evidence pack: heuristics, screenshots, optional human_note

Also: POST /qa_note/{job_id} (MCP qa_note) to close needs_review. Streamable-HTTP MCP is POST /mcp on this same host. Health: GET /health.

Rules

  • https only. Public preview URLs. Vercel/Netlify-style links are the point.
  • Localhost / private rejected. 127.0.0.1, RFC1918, link-local, CGNAT, metadata IPs, file://, embedded credentials, redirect-to-private.
  • v0 public preview: about 20 preview jobs per day per IP so this URL is not an open screenshot farm.

mcp.json

Cursor: add to .cursor/mcp.json (omit type; a url is streamable HTTP). Key optional in v0.

{
  "mcpServers": {
    "shipcheck": {
      "url": "https://THIS-HOST/mcp",

  }
}
